Wireflow 定价方案 ​

文档目的：定义 Wireflow 产品的商业定价模型、功能分层及授权规则，为 License 实现（2.2）和官网定价页提供依据。

当前日期：2026-04-27

一、定价总览 ​

Wireflow 采用 Open Core 模型：Community 版永久免费开源，Pro 版通过 License Key 解锁企业级功能。

版本交付形态计费方式适用场景
Community自托管（开源）永久免费个人开发者、小型团队、测试环境
Pro 自托管自托管（闭源二进制）按节点数阶梯 + 年付有运维能力的中大型企业
Enterprise 自托管自托管（含源码授权可选）自定义合同超大规模 / 特殊合规需求
SaaS 托管云端托管（后期推出）按节点数 + 月付无运维团队的中小企业

三、Pro 自托管定价 ​

定价原则 ​

  • 计费维度：受 License 管控的在线节点峰值数（即 max_nodes 字段）
  • 付款周期：年付，一次性授权一年
  • License 绑定：每个 License 绑定一个部署实例（通过 latticed 实例 ID 校验，防止多处复用）
  • 到期策略：License 到期后 Pro 功能降级为 Community 行为，不影响网络连通性

套餐 ​

套餐节点上限年费（USD）备注
Starter25 节点$499 / 年适合小型私有云、实验室环境
Professional100 节点$1,499 / 年适合中型企业 / 多机房互联
Business500 节点$3,999 / 年适合大型企业 / 边缘计算场景
Enterprise无限制询价含 SLA、专属支持、可选源码授权

首年优惠（Early Adopter）：前 50 个付费客户在上述价格基础上享受 6 折优惠，且该折扣在续费时锁定保留。

超量处理 ​

  • 节点数超过 max_nodes 时，API 返回 402 Payment Required，新节点无法注册
  • 前端显示升级引导弹窗，包含当前用量和推荐套餐
  • 客户可随时升级套餐，差价按剩余天数折算

续费政策 ​

  • 到期前 30 天发送提醒邮件
  • 连续续费享 9 折优惠（连续两年以上）
  • 不续费则 License 自动失效，降级为 Community

四、私有部署 / Enterprise 授权 ​

适合以下场景：

  • 节点数超过 500 或无法预估
  • 有内网隔离要求，不允许任何出站联网校验
  • 需要源码授权用于合规审计
  • 需要定制功能开发

报价构成 ​

一次性 License 费用（买断当前版本）
  + 年度维护费（获取后续版本更新 + 技术支持）
  [可选] 源码授权附加费
  [可选] 定制开发费（按天计费）

参考价格区间 ​

项目价格区间（USD）
一次性 License（无限节点）$15,000 ~ $30,000
年度维护费（License 购买价的）20%
源码授权附加$10,000 起

具体金额根据客户规模、所在行业、合同期限协商确定。

五、SaaS 托管定价（后期推出） ​

SaaS 版由 Wireflow 官方托管控制面，客户只需部署 wireflow 节点 Agent，无需维护 latticed。

套餐（月付） ​

套餐节点上限月费（USD）折合年费
Starter25 节点$49 / 月$490（优惠 2 个月）
Professional100 节点$149 / 月$1,490
Business500 节点$399 / 月$3,990
Enterprise无限制询价—

SaaS 版包含高可用托管、自动备份、Web 控制台；不包含源码访问权限。

六、License 授权规则 ​

以下规则需在 License JWT 中强制校验（对应 internal/license/ 实现）：

json
{
  "customer": "Acme Corp",
  "plan": "pro",
  "tier": "professional",
  "max_nodes": 100,
  "instance_id": "wfd-abc123",
  "issued_at": "2026-04-27T00:00:00Z",
  "expires_at": "2027-04-27T00:00:00Z",
  "features": ["monitoring", "sso", "turn", "telemetry"]
}
字段用途
max_nodes在线节点峰值上限，超出时拒绝新节点注册
instance_id绑定特定 latticed 实例，防止 License 共享
expires_at到期后 Pro 功能自动降级，不中断网络
features细粒度功能开关，支持按需授权（如仅授权 SSO 不含监控）

校验失败行为 ​

场景处理方式
License 文件不存在以 Community 模式启动，Pro 路由返回 402
签名校验失败启动失败，日志输出 invalid license signature
License 已过期降级为 Community，API 返回 402 并附带过期提示
节点数超限新节点注册返回 402，现有节点不受影响
实例 ID 不匹配启动失败，日志输出 license bound to different instance

七、Free Trial 策略 ​

为降低决策门槛，提供 30 天全功能免费试用：

  • 发放一个特殊 Trial License（"plan": "trial"，max_nodes: 25）
  • 官网填写邮件 + 公司名即可获取，无需信用卡
  • Trial 期间功能与 Pro Professional 套餐一致
  • 到期后自动降级为 Community，数据不丢失

八、定价决策记录 ​

决策理由
按节点数而非按用户数计费Wireflow 核心价值是网络节点管理，节点数更直接反映用量和价值
Community 不限节点数降低开源用户门槛，开源社区是增长飞轮；节点数限制对已有 WireGuard 用户没有吸引力
年付为主提高客户生命周期价值（LTV），减少每月续费流失
License 绑定实例而非 IP实例 ID 更稳定（IP 变化频繁），K8s 环境 Pod IP 尤其不可靠
到期降级而非停服保护客户网络不因付款延误中断，降低客户续费阻力
首年 Early Adopter 折扣锁定吸引早期客户，锁定折扣增加续费粘性
